# サイゼをつくろう

Three.js の非公式サイゼリヤ風レイアウトアプリです。2Dで配置し、その店内を3Dで歩いて撮影できます。特定店舗の寸法を正確に復元するものではありません。

## すぐ試す

`npm ci`、`npm run build:standalone`で生成される「standalone/サイゼをつくろう.html」が、画像・CSS・JavaScriptを内蔵した単体版です。ChromeまたはEdgeで開いて使います。WebGLが必要です。ブラウザによってローカルファイルの自動保存が制限される場合は、JSONの書き出し／読み込みを利用してください。

「サンプル店舗.json」は斜めの角・灰色椅子・3点の絵画・Serviを配置した例です。アプリの「読み込み」から開けます。

## 開発用起動

Node.js 22.13以上で、このフォルダから `npm install`、`npm run dev`。表示されたローカルURLを開きます。

## 操作

- 家具を選び、床をクリックして配置。ドラッグで移動、Rで90度回転、Deleteで削除。
- Ctrl+Zで元に戻す、Ctrl+Shift+Zでやり直し。部屋の形と椅子の変更も戻せます。
- 「椅子のタイプ」で、籐編み／グレー・フック付き／グレー・丸穴の背もたれを店内一括切り替え。2人席セットと単体椅子が対象です。提供写真に合わせ、籐椅子はひし形の編み込みと黒い巻き帯、ベンチは淡い黄緑の縦縞の背・濃緑の薄い座面にしています。
- 「部屋の形をつくる」で角をドラッグ。壁の＋で角を追加。選択した角は座標入力・削除ができます。
- 「直角を保つ」ONは隣の角も連動。OFFは斜めの壁。長方形・L字・斜めの角のプリセットもあります。
- 壁が交差する形は適用不可。新しい壁にはみ出す家具は、明示的に片付けを選ぶか、家具の配置を直してください。
- 絵画は壁に自動で沿って配置。背の高い装飾なので家具の上にも置けます。絵画を掛けた壁は窓から壁面になります。
- Serviは5台まで。3Dに入ると料理を配膳し、皿を回収して厨房の扉から出入りします。厨房は通れる壁際に自動配置されます。人や他のロボットに近づくと待機し、「一時停止」で全台停止できます。通路が狭い場合は家具を移動してください。
- 家具と仕切りは端に吸着します。4人席・ベンチは「背中合わせに追加」で隙間なく並べられます。
- 《アダムの創造》《受胎告知》《アテナイの学堂》とサイゼリヤのロゴパネルを追加。ロゴは壁の内側／外側を切り替えられます。
- 卓上小物を外し、公式メニュー表紙を配置。2026年10月22日に公式一覧で確認した2026年6月版です。自動更新ではありません。画像の出典はアプリ内と app/assets/SOURCES-new.md に記載しています。
- 3Dはドラッグで見回し、WASD／矢印で歩き、Shiftで早歩き。画面の矢印ボタンでも移動できます。
- 「写真を保存」は操作パネルなしの1920×1080 PNG。昼夜も切り替えられます。
- 変更はこのブラウザに自動保存。JSONは部屋の形・全配置・椅子タイプを含みます。旧版の家具だけのJSONも読み込めます。

## 検証

`npx tsc --noEmit` と `npm run build` を実行。実ブラウザで配置、椅子切替、絵画表示、斜め壁編集、角の追加／削除、3D歩行、ロボット移動／停止、再読み込みでの保存復元、PNG出力、スマートフォン幅を確認しました。図形・配置・経路の検証では、斜め壁、交差する壁、入口と家具の衝突、不正JSON、旧形式の復元、ロボット経路258ステップ、閉じた通路を確認しています。

単体HTMLは同じ実装から生成していますが、ブラウザ操作ツールではfile URLを開けないため、file方式での実ブラウザ検証はできていません。HTTPの開発プレビューで動作を確認しました。

## 単体HTMLの再生成

このフォルダで `npm run build:standalone`。単体HTMLは `standalone/サイゼをつくろう.html` に生成されます。

## 公開状態

ローカルの最新版です。既存の公開サイトへの更新は、ソース同期時の認証情報受け渡しが自動承認レビューで拒否されたため未実施です。

## 内装の追加修正
ベンチ座面は横長1枚、背もたれは横長2段で左右の継ぎ目なし。仕切りは厚さ36mm（従来の20%）の板と丸い上角に変更し、2D・衝突判定も同じ厚さにしています。植物は薄く湾曲した葉・葉脈・枝・土と鉢の縁を追加。各テーブルには、現在の公式設備案内を参考にした4段カトラリーケース一体型のメニュー立てを追加しました。

## 料理と壁面の更新
絵画の額を従来の20%の厚みに変更。ロゴは公式画像のアルファ輪郭を使い、四角い下地を除去しました。料理・ワインのON/OFFは2Dと3Dにあり、JSON・自動保存にも含まれます。OFF時は平置きメニューに戻ります。ミラノ風ドリア・マルゲリータ・辛味チキンの簡易3Dモデルをテーブルごとに組み合わせ、マグナムボトル・グラス・取り皿を添えています。


## 配膳・着席と視点設定
料理を8種類に拡充。小さいテーブルは2品、大きいテーブルは5品を配置します。赤・白ワインは脚付きグラスで一部の席に置き、他の席には水・ジュースを配置。マグナムも赤・白を用意し、メニュー立てにおすすめ札を添えています。卓上の余白と壁への接触をチェックして位置を調整します。
近くの椅子をクリックすると着席。ベンチはクリックした左右の位置に座ります。ドラッグで見回し、Eまたは「立ち上がる」で元の立ち位置へ戻れます。「視点設定」で左右・上下のドラッグ反転を個別に変更でき、設定は自動保存・JSONに含まれます。
5台のロボットについて400秒の移動・接触・配膳・回収・厨房出入りのシミュレーションを検証。32組の料理について卓上範囲と品数を検証しています。


## ランダム生成と卓上配置
ランダム室内は部屋の形と家具を、ランダム配置は現在の部屋の家具を作り直します。元に戻すで復元できます。通路を残した列配置と経路検証を使い、初期配置・生成店舗にはロボットを3台配置します。保存済みの店舗は自動で変更しません。メニュー立ては短辺中央、短辺で隣接するテーブルでは背中合わせになります。
検証コマンド: npm run test:layout。Pages公開は npm run build:standalone の生成HTMLを index.html にして配信します。

## 密度・寸法と走行音
着席視点は床から1.30m。天板の厚みは従来の60%、メニュー立ての奥行きは30%です。おすすめ札は撤去し、料理OFF時の平置きメニューは天板中央へ配置。ランダム生成では約1.55mの主通路、背中合わせの3卓ブロック、複数の壁画を使用します。走行音は3D画面のボタンでON/OFFでき、初期状態はOFF。動いているロボットの距離に応じた合成モーター音です。
